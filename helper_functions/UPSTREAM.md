# helper_functions/

`cluster.R`, `colors.R`, `globals.R` and `libraries.R` are taken unchanged from
the public repository of the study that generated GSE275938:

  Shirazi SP, Negretti NM, Jetter CS, et al.
  https://github.com/SucreLab/HumanNeonatal

They are included here only so that the preprocessing and annotation scripts in
`scripts/` can be run as they were. Please cite the original study when using
them, and check that repository for the current version and its licence.
